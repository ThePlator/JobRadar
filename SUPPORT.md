# Getting help

- **Setting it up:** follow [Getting Started](https://github.com/ThePlator/JobRadar/wiki/Getting-Started) and [Notion Setup](https://github.com/ThePlator/JobRadar/wiki/Notion-Setup).
- **Something fails:** check [Troubleshooting](https://github.com/ThePlator/JobRadar/wiki/Troubleshooting) and the [FAQ](https://github.com/ThePlator/JobRadar/wiki/FAQ). `uv run jobradar stats` shows failed tasks and their errors.
- **Still stuck, or found a bug:** [open an issue](https://github.com/ThePlator/JobRadar/issues/new/choose) with the bug template. Remove tokens, keys, phone numbers and session files from anything you paste.
- **Security problem:** don't open an issue; see [SECURITY.md](SECURITY.md).

JobRadar is maintained in spare time, so replies can take a few days.
